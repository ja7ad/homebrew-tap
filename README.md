# Homebrew Tap for Hydra

Official Homebrew tap for [Hydra](https://github.com/ja7ad/hydra) — a fast, resilient, multi-source file retriever and download engine.

## Installation

### CLI

```bash
brew install ja7ad/tap/hydra
```

### macOS Desktop App (GUI)

```bash
brew install --cask ja7ad/tap/hydra
```

## Updating

```bash
brew update
brew upgrade hydra
brew upgrade --cask hydra
```

## Documentation

For more information, usage guides, and full documentation, visit the [Hydra repository](https://github.com/ja7ad/hydra).
